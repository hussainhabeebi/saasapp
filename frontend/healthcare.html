Getting started
🏬 Departments — Cardiology, Dermatology, Dentistry, etc. Each can carry up to 3 photos, auto-sent to chat the first time a patient's message names that department.
🩺 Doctors — a profile per doctor under a department: qualification, specialization, experience, consultation fee, up to 5 photos, an intro video, and a PDF (CV/certificate) — sent to chat whenever a lead asks about that doctor.
