⏰ Preferred Send Window
A step that becomes due outside this window waits for the window to open instead of firing right away — nothing is skipped, just delayed to the next time it's within hours. Defaults to evenings, after typical office hours, since that's usually when a lead actually has time to reply on WhatsApp.
💪 Follow-up Engine
Every follow-up setting lives here now. The first two nudges go out as normal WhatsApp messages while the conversation is still "open" (within 24 hours) — after that, WhatsApp only allows pre-approved template messages, so the 25-hour/3-day/7-day re-engagement steps each need a template chosen below (sent directly via the WhatsApp Cloud API, not through Chatwoot). For ecommerce clients, a session-step message automatically gets a real low-stock line appended (e.g. "Only 3 left in…") whenever the lead's last-shown product is genuinely running low — never a fabricated countdown.
📱 Before 24 Hours — Session Messages
📋 After 25 Hours — Template Message
Sent via WhatsApp Cloud API using a pre-approved template. WhatsApp requires a template once the 24-hour session window closes.
📋 After 3 Days — Template Message
A second re-engagement attempt 3 days after the last customer reply.
📋 After 7 Days — Template Message
Final re-engagement attempt 7 days after the last customer reply.
